# 信息收集表

写一篇案例文前,对照本表核对素材。分三档:缺★必需项就停下问用户;◇增强项能显著提升质量,值得问一嘴;○可选项有则用。

## 一、学生档案(★必需)

| 项 | 说明 | 脱敏规则 |
|---|---|---|
| 化名/代号 | 如 J同学、Mike | 不用真名 |
| 本科院校 | 精确或梯队(美本TOP30/国内985/英国G5) | 敏感时只写梯队 |
| 专业 | | |
| GPA | 数字或区间(3.3+) | |
| 标化 | GRE/GMAT/雅思托福,没考或没提交也是素材(反差点) | |
| 录取列表 | 学校+项目全名,含奖学金金额 | 这是卖点,尽量全 |
| 最终去向 | 选了哪个,为什么 | "放弃X选Y"本身是钩子 |
| 申请时间线 | 什么时候签约、关键节点 | "大二就开始"/"11月才换机构"都是素材 |

## 二、故事核心(★必需)

1. **最大短板/反差**:按理说这个背景哪里"不该录"?(低GPA/标化崩/转专业/零实习/起步晚/经历散)
2. **学生找来时的状态**:原话最好("完全没有方向""对中介不信任""朋友圈被offer刷屏很焦虑")
3. **我们做的具体动作(3~5个)**:每个动作要能回答"具体做了什么+和别家有什么不一样"。例:不是"指导文书",而是"没沿用旧文书,重新聊了一小时经历,把四段散实习串成'数据如何进决策'一条线"
4. **结果与因果**:哪个动作最可能导致了哪个结果

## 三、关系与服务证据(◇强烈建议要)

- 1~2个**编不出来的细节**:半夜回消息的时间戳、学生发来的表情包/熊猫视频、线下见面的场景、某次崩溃时说的话
- **转介绍链**:学生怎么知道我们的(学长推荐/小红书/朋友录了哪里)——本身就是社交证明
- **聊天记录/服务过程截图**:标注哪几张可用,写进配图位
- **超出合同的时刻**:介绍行业朋友、劝学生别乱花钱、offer后还帮选校

## 四、学生语料(◇,决定能否用B体例)

- 学生访谈回答(书面或口述整理)
- 学生愿不愿意"出镜"答问
- 保留学生口语的粗粝感:自嘲、语气词、小语病都是真实感,别改成书面语

## 五、学生文书(○可选,但价值极高)

### 文书使用规则(必须遵守)

1. **提炼,不搬运**:从文书里挖三样——①叙事主线(招生官看到的那条线)②具象场景(能进正文的画面,如"农民在黑板上用粉笔预测产量")③动机细节(为什么选这个方向)。
2. **引用限制**:直接引用原文每处不超过25字,全篇不超过2处;引用时标注"她在文书里写道"。
3. **脱敏**:文书里的公司名→"行业+规模"(某头部券商/北美中型药企);教授名、项目组名删除。
4. **不泄卖点**:文书全文结构、完整故事线不完整披露——展示"我们能把散经历写成线"的能力,不展示可被抄袭的成品。
5. 文书是 PDF/docx 时先转文本再读。

## 六、品牌与发布信息(★必需,但通常从品牌库读)

- 机构/账号名、顾问老师称呼(如 Shawn 老师)
- CTA方式:扫码加好友/私信钩子词(如发送"剑桥")/进群
- 本篇目标读者画像(决定反差和建议板块写给谁):低GPA焦虑型 / 转专业型 / 早规划家长型 / 求职导向型

## 七、缺项追问模板

必需项缺失时,用 AskUserQuestion 一次问全,示例问法:

- "这个学生按理说最'不该录'的一点是什么?(GPA/标化/背景/时间,选一个最痛的)"
- "我们为他做的事里,挑3件最具体的:每件说清'做了什么+花了多久/几次/到几点'"
- "有没有一个外人编不出来的细节?(某次深夜沟通/他发来的一句话/一张截图)"
- "学生本人愿意以问答形式出现吗?有他的原话吗?"

## 八、学员访谈 8 问(B体与四栏短页的主要素材)

由班主任或后端顾问发给学生书面回答,发之前先确认学生同意公开分享(授权写进合同授权条款或单独确认)。问题参照 PH 七年固定问卷的信息槽,按我们的服务环节重写;每问后面是要追问到的细节,学生答得笼统就追问一次。

1. 当时怎么找到我们的?比较过哪几家,最后为什么定下来?(追问:谁介绍的;哪一次沟通让你决定)
2. 刚开始申请时,你最担心的是什么?(追问:当时的分数、时间点、原话)
3. 你最后去的项目,当时看了它哪几门课?为什么是它?(追问:课号或课名;手上有没有更好的 offer,最后怎么比、为什么没去)
4. 文书一共改了几稿?改动最大的是哪一稿,改了什么?(追问:哪位老师、删掉或留下了哪段)
5. 推荐信找了谁,怎么开口的?(追问:几封、校内校外怎么搭)
6. 面试准备了几次?印象最深的一个问题是什么?
7. 有没有没录上或主动放弃的项目?拿到 offer 后犹豫过什么?
8. 给和你背景相似的学弟学妹一条建议。(这一问的回答通常就是全文结尾那句学员原话,追问到具体:哪件事、什么时候做、为什么)

可选:想对哪位老师说一句话(不答也可以;答了原文照录,不改写)。

顾问寄语另问经手顾问一个只有经手人才知道的细节:开会时学生说过的一句话、某个项目几号截止、第一封 offer 几月到、当时学生人在哪里。
