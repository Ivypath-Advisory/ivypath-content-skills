# 体例结构模板(A/B/C竞品蒸馏体)

> **默认体例是 D体·IvyPath主笔叙事体,规范在 `house-style.md`(我们自己的口吻,优先)。**
> 本文件是竞品蒸馏的三种备选体例:清柚(A体)、Emma/棕榈/PH(B体)、Emma导师专访(C体)。
> 共同骨架不变:**反差 → 主线 → 具体动作 → 结果 → 代入出口**。体例只是外壳。

## 体例决策树

```
默认 → D 主笔叙事体(house-style.md)
但:学生愿出镜、有鲜活口语语料 → B 学生访谈问答体
   方法论价值>故事价值/立导师人设 → C 导师专访复盘体
   A体已被D体取代,仅作竞品结构参考
```

字数基准:1800~2800字(不含服务特色尾部)。

---

## A · 第三人称成长叙事体

适合:素材只有顾问视角;学生低调。风险:最容易写出AI味和软文腔,服务动作必须格外具体。

```
1. 学员档案卡(院校/专业/GPA/标化/录取列表)——放最前,承担搜索与信任
2. 章节1 · 起点:兴趣或目标的来源,埋下主线(300字)
3. 章节2 · 转折/困境:短板暴露的具体场景,学生找到我们时的状态(300字)
4. 章节3 · 策略:我们的判断和与学生预想不同的建议(混申思路/冲刺鼓励/补哪段实习),
   写清"为什么这么判断"(400字)
5. 章节4 · 执行:文书怎么打磨(两个申请方向侧重点差异)、实习怎么补、面试怎么模拟,
   每个动作配一个具体细节(500字)
6. 章节5 · 放榜:结果堆叠,第一个offer到来的时刻感(200字)
7. 祝福 + 真实案例声明 + CTA
```

小标题写法:内容化短语,直接说事(如「补一段实习,填上最后的缺口」),别用空泛四字对仗(「厚积薄发」「圆梦名校」这类是竞品的AI腔,不学)。

## B · 学生访谈问答体(默认)

适合:有学生语料。这是12篇中数据与信任表现最好的体例。

```
1. 编辑导语(200~300字):
   - 第一句交代这是谁+跟了多久("从大二就开始辅导规划的学员")
   - 「典型化」一句:"她的情况其实很典型:____"(读者代入的入口)
   - 两个核心难点预告 + 结果一句带过
   - "希望对同样在准备的同学有参考"
2. 导师寄语(顾问第一人称,150~250字):
   - 认识学生的场景细节(谁介绍的/第一印象/去学校看过她排练戏剧社)
   - 一句难点回顾 + 一句结果 + 一句祝愿
   - 这是"关系"的主展示位,必须有至少1个编不出来的细节
3. 学生档案卡(本科/GPA/录取项目列表)
4. Q&A 5~7问,推荐问题序列(按素材取舍):
   Q1 怎么了解到我们的?为什么选我们?(转介绍链+和前一家中介的对比)【固定模块1】
   Q2 你申请中最大的短板是什么?怎么补的?(反差主战场)【固定模块2/4】
   Q3 选校名单是怎么定下来的?(定位判断+冲刺/匹配/保底逻辑+为什么有这些"没想过敢申"的项目)【固定模块3】
   Q4 文书是怎么写出来的?(主线怎么找到的、具体到某一篇怎么改、思维怎么被扭转)【固定模块5】
   Q5 印象最深的一次辅导/面试准备?(服务细节主战场)
   Q6 给学弟学妹的建议(3条,可操作)【固定模块7】
   Q7 为什么最终选了X项目?对未来的期待?(定校理由+项目冷知识)【固定模块6】
5. 每1~2个Q后插一个「IvyPath小贴士」(机构视角插播,100~200字):
   把个案升维成方法论,面向"如果你也是____的同学"
   (板块名是品牌固定叫法,来源于竞品"Emma补给站"的设计,名字必须用我们自己的)
6. 结尾:金句(从学生原话里挑,别造)+ CTA(扫码+钩子词)
7. [可选] To 学生的祝福短信(第二人称,含私人细节)——PH式,关系感拉满
```

学生答问的语言规则:保留口语、自嘲、情绪("我当时还挺崩溃的""说不焦虑是假的");加粗只用于关键结论句;禁止把学生的话改成机构腔。

## C · 导师专访复盘体

适合:方法论价值>故事价值;学生不出镜;想立"专业深度"人设。

```
1. 战绩导语:"近两年我们拿下N枚XX录取"+本案一句话(反差点)
2. 导师寄语(短)+ 学生档案卡
3. Q&A 4~6问,全部问方法,用本案作证据:
   Q1 这个案例最反常识的决策是什么?(如:不把她包装成"高度垂直",反而重新定义分散)
   Q2 具体怎么操作?(把散实习串成一条问题主线的过程,举2段实习怎么写)
   Q3 常见错误是什么?(别人会怎么写砸)
   Q4 这几年录取这个项目的学生共性?(3条)
   Q5 新一年申请者该怎么应对?
4. 每问的回答结构:观点一句 → 本案证据(具体到实习内容/文书段落思路) → 方法一句
5. 结尾:给读者的判断标准(不是鸡汤)+ CTA
```

## 通用部件

**档案卡格式**(所有体例必有):

```
【学生档案】X同学
本科:____  专业:____
GPA:____  GRE/GMAT:____(没提交也写,注明策略)
>>> 录取项目
学校 - 项目全名(奖学金$____)
...
最终去向:____
```

**配图位**(正文标注 `[配图:____]`,caption承担服务证据):

- 聊天记录截图:caption 写"老师半夜还在改文书的批注"/"每一步进度都有提醒"
- offer截图(2~3张)
- 服务过程:文书批注截图、meeting纪要、选校表格
- 学生供图(校园/夏校),标注"学员供图,禁止转载"

**文末固定件**:真实案例+隐私保护声明一句 + CTA(扫码/钩子词)。
