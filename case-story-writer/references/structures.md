# 体例结构模板(A/B/C竞品蒸馏体)

> **默认体例是 D体·IvyPath主笔叙事体,规范在 `house-style.md`(我们自己的口吻,优先)。**
> 本文件是三种备选体例:清柚式(A体,已停用)、学员访谈体(B体,结构参考 PH,批量篇默认)、导师专访(C体)。
> 共同骨架不变:**反差 → 主线 → 具体动作 → 结果 → 代入出口**。体例只是外壳。

## 体例决策树

```
默认 → D 主笔叙事体(house-style.md)
但:有学员访谈问卷 / 学生愿出镜、批量篇 → B 学员访谈体
   方法论价值>故事价值/立导师人设 → C 导师专访复盘体
   A体已被D体取代,仅作竞品结构参考
```

字数基准:1800~2800字(不含服务特色尾部)。

---

## A · 第三人称成长叙事体(已停用,只作结构参考,新稿不用)

适合:素材只有顾问视角;学生低调。风险:最容易写出AI味和软文腔,服务动作必须格外具体。

```
1. 学员档案卡(院校/专业/GPA/标化/录取列表)——放最前,承担搜索与信任
2. 章节1 · 起点:兴趣或目标的来源,埋下主线(300字)
3. 章节2 · 转折/困境:短板暴露的具体场景,学生找到我们时的状态(300字)
4. 章节3 · 策略:我们的判断和与学生预想不同的建议(混申思路/冲刺鼓励/补哪段实习),
   写清"为什么这么判断"(400字)
5. 章节4 · 执行:文书怎么打磨(两个申请方向侧重点差异)、实习怎么补、面试怎么模拟,
   每个动作配一个具体细节(500字)
6. 章节5 · 放榜:结果堆叠,第一个offer到来的时刻感(200字)
7. 祝福 + 真实案例声明 + CTA
```

小标题写法:一句让人想读下去的话,不写「起点:」这类栏目名(如「没修过线代,申耶鲁是不是想多了?」),别用比喻、意象和空泛四字对仗(写法同 house-style.md「小标题」)(「厚积薄发」「圆梦名校」这类是竞品的AI腔,不学)。

## B · 学员访谈体(批量篇默认)

适合:有学员访谈问卷回答(intake-form.md 第八节 8 问)或学员愿意出镜。批量出稿时优先用它:素材来自学员原话,人味靠原话撑着,编辑只做删减、排序和衔接。
依据:PH 2019-2026 年 512 篇案例文的骨架七年基本没变,人味主要来自学员原话保留得多;2026 年 PH 改成「两行小标题 + 编辑整理成段落」后,「不是…而是」「真正」、破折号的密度都明显上升(见 Project 文档《PH案例文写作模式分析-538篇全文》)。所以整理时不替学员加判断句、不加升华句。

```
1. 编辑导语(150~300字,短行为主):
   - 一个反差或悬念 → 点出学员化名和结果 → 「以下是她的申请经历」
   - 「典型化」一句:"她的情况其实很典型:____"(读者代入的入口,全篇一次)
2. 学员档案卡(本科/专业/GPA/标化/全部录取/最终去向/实习与科研一句)
3. 顾问寄语(经手顾问或班主任第一人称,对学生用「你」,120~250字):
   - 至少一个只有经手人才知道的细节:开会时学生说过的一句原话、某个项目几号截止、第一封 offer 几月到、当时学生人在哪里
   - 一句祝愿收住,不写金句
   - 放在正文前(2026-11-03 起全文用学员自己的话结尾,寄语不再放文末)
4. 学员第一人称正文,按访谈 8 问的顺序分节:
   Q1 怎么找到我们、比过谁、为什么定下来【固定模块1】
   Q2 找来时最担心什么,短板怎么补【固定模块2/4】
   Q3 最后去的项目,你当时看了它哪几门课?为什么是它?(单校课程深挖的学员版;手上有更好的 offer 却没去时,这一节就写录取后两个项目怎么比、为什么选了现在这个,见 house-style.md「录取后的项目权衡」。学员没写清课名时,编辑按官网核对后写在节末的【编者注】里,只写课名和内容,课号进出处表,不塞进学员原话)【固定模块3】
   Q4 文书改了几稿,改动最大的一次改了什么【固定模块5】
   Q5 推荐信、面试各准备了什么(次数、印象最深的一个问题)
   Q6 拿到 offer 后怎么选的,犹豫过什么【固定模块6】
   Q7 给背景相似的同学一条建议【固定模块7】(全文最后一节,学员的话就是全文结尾;编辑不再加总结或升华)
   - 小标题两种写法任选其一,全篇统一:问句(「文书改了几稿?」)或两行式(第一行写事实「4天改26稿」,第二行写这件事带来的变化);第二行不写「不是…而是」、不写「真正」
   - 学员的口语、犹豫、自嘲、英文夹杂(offer / mock / AO / why program)照留,不改成书面语
   - **原话区**:每节的学员答问在工作稿里用 `::: 原话` 和 `:::` 两行包起来,发布前删掉这两行。原话区里编辑只能删、调顺序、补必要的主语,不能改写或加句子;lint 不把原话区计入句式限额。原话区外的导语、小贴士、编者注、顾问寄语照常计数
   - 问句小标题可以用「你」(这是在转述访谈提问)
5. 每 2~3 节后插一个「IvyPath小贴士」(机构视角,100~200字,面向"如果你也是____的同学"),全篇 1~2 个,不放在 Q7 之后
6. CTA(扫码 + 钩子词)+ 真实案例声明
```

**每篇硬性下限**(缺了回问卷或问顾问,不造):
- 一个没录上或主动放弃的项目,写明原因
- 一个犹豫过的决定
- 具名角色(文书导师 / 班主任 / 规划顾问,可用称呼不用全名)加上他们做的具体动作
- 至少一个数字(改了几稿、几次 mock、几号截止)

学员答问的语言规则:保留口语、自嘲、情绪("我当时还挺崩溃的""说不焦虑是假的");加粗只用于关键结论句;禁止把学员的话改成机构腔;不替学员说他没说过的判断。

## C · 导师专访复盘体

适合:方法论价值>故事价值;学生不出镜;想立"专业深度"人设。

```
1. 战绩导语:"近两年我们拿下N枚XX录取"+本案一句话(反差点)
2. 导师寄语(短)+ 学生档案卡
3. Q&A 4~6问,全部问方法,用本案作证据:
   Q1 这个案例最反常识的决策是什么?(如:把她几段分散的经历归到同一个问题下,没有硬写成只做一个方向的人)
   Q2 具体怎么操作?(把散实习串成一条问题主线的过程,举2段实习怎么写)
   Q3 常见错误是什么?(别人会怎么写砸)
   Q4 这几年录取这个项目的学生共性?(3条)
   Q5 新一年申请者该怎么应对?
   选校相关的问题按 house-style.md「选校段」:只挖最好那枚 offer 的课程,不讲三层名单
4. 每问的回答结构:观点一句 → 本案证据(具体到实习内容/文书段落思路) → 方法一句
5. 结尾:本案结果一句(去向 + 一个朴素理由)→ 给读者一条可操作的判断标准 → CTA;不写金句
```

## 通用部件

**档案卡格式**(所有体例必有):

```
【学生档案】X同学
本科:____  专业:____
GPA:____  GRE/GMAT:____(没提交也写,注明策略)
>>> 录取项目
学校 - 项目全名(奖学金$____)
...
最终去向:____
```

**配图位**(正文标注 `[配图:____]`,caption承担服务证据):

- 聊天记录截图:caption 写"老师半夜还在改文书的批注"/"每一步进度都有提醒"
- offer截图(2~3张)
- 服务过程:文书批注截图、meeting纪要、课程对比表(单校课程,不放完整申请名单)
- 学生供图(校园/夏校),标注"学员供图,禁止转载"

**文末固定件**:真实案例+隐私保护声明一句 + CTA(扫码/钩子词)。
