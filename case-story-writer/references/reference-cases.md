## 授权分级（目录的「授权状态」列）

- **A 授权清单**：PH 授权清单内的文章，可以进上线流程。第一次用前先跟 Daniel 确认授权范围（文字、图片分别能否用）。
- **B 本团队经手**：清柚数据表里的学员，是我们团队当年服务的学生，可以写成我们的案例，但按改稿模式（rewrite-mode.md）走：清柚原文和图片一张不用（前东家物料），事实以数据表、后端记录和学生提供的原件为准，上线前必须确认学生授权。
- **C 仅培训**：其余全部（PH 非授权文、常青藤、拓达、清柚非本团队学员）。只做训练用：页眉写「培训样稿｜改编自外部公开案例｜不得发布」；不进官网、公众号、小红书等任何对外渠道；不能说成 IvyPath 学员。

清柚数据表含学员真名，只在本地 Excel 里用，不进任何托管页面、仓库或对外稿。

## 匹配层级（先高后低，够数就停）

用 Python 读目录 CSV（`encoding="utf-8-sig"`）。学校名统一中英文和简称：罗格斯 = Rutgers = RU，石溪 = Stony Brook = SBU，雪城 = Syracuse，康大 = UConn，纽大 = NYU，上纽 = NYU Shanghai，UCSD = 加州大学圣地亚哥分校，以此类推。

- L1 同本科 + 同录取项目（或同一个白皮书 05 节项目）
- L2 同本科 + 同白皮书方向
- L3 同类院校 + 同项目或同方向：UC 系互补；罗格斯 / UConn / 石溪互补；布兰迪斯 / 雪城互补；NYU / NYU Shanghai 互补
- L4 任意本科 + 同项目

## 打分排序

最终去向在本方向 +3；录了白皮书 05 节项目 +2；2025 季及以后 +2，2023–2024 季 +1；PH 正文 ≥3,000 字 +1；有 GPA +1；本方向录取每个 +0.5（最多 +1.5）。

## 按来源判断能学什么

- 学写法优先选 PH：学员第一人称访谈，人味最足，对应我们的 B体。
- 清柚只列录取，适合看同背景能录哪些项目，不适合模仿写法。
- 常青藤、2025 下半年以后的拓达 AI 腔重，只当反面示例。
- 用途为「上线」时只出 A / B 级。
