# 质检 Rubric(不过不交)

语言终审归 ivypath-humanize-zh(案例文档);本文件只放案例文专用的自评、合规、独创性和专项清单。
市场库 `01_品牌中枢/品牌禁用语.md` 里有本文件没有的禁用语时一并执行;`去AI味写作规范.md` 与本文件冲突时按本文件(优先级见 SKILL.md)。
句式计数先跑 `python3 scripts/zh_lint.py 成稿.md --genre case`,再人工复核。

## 一、去AI味自评(满分10,≥8才交付)

| 项 | 满分 | 扣分点 |
|---|---|---|
| 无AI高频词(赋能/打造/全方位/深耕/助力/保驾护航/至关重要/淋漓尽致/颠覆/闭环) | 2 | 每个扣1 |
| 句式:"不是X而是Y"(含不只是/不在于/并非…而是)每篇≤1次且只用于加粗理念句(2026-11-03 定,各体例统一);破折号连接半句≤1处;对仗三连(高效、专业、贴心)≤1次 | 2 | 每超一处扣0.5 |
| 无空心词(真正≤1/其实/值得一提的是/或许/某种程度上/不得不说);学员原话、定稿句和 house-style 的 DNA 句式不计 | 1 | 每个扣0.5 |
| 每个"好/优秀/值得"都换成了具体数字或原因 | 2 | 每处空泛点评扣1 |
| 开头无"在当今…时代";结尾无"未来可期/拭目以待/综上所述";事实清单后不挂总结尾巴 | 2 | 各扣1 |
| 读起来像真人机构在讲一个真学生,不像通稿 | 1 | 主观 |

案例文高危AI腔(竞品清柚体的教训,专项排查):
"浓墨重彩的一笔""大放异彩""脱颖而出"(≤1次)"抛出橄榄枝"(≤1次,标题正文合计)"圆梦名校""厚积薄发"式四字对仗小标题、每段结尾的升华句。

## 二、合规清单(一票否决)

- [ ] 无禁用语:保录 / 包过 / 保证 / 100%录取 / 包装背景 / 走捷径 / 内部资源 / 名校随便拿 / 低分也稳了 / 最强 / 全美第一、行业第一这类「第一」(序数「第一次 / 第一封 / 第一类」不算);zh_lint 同口径
- [ ] 不暗示与学校有特殊录取关系;不暗示代写、造假
- [ ] 不承诺结果、签证、实习、工作("这个案例不代表每个学生都适用,但策略值得参考"是标准姿势)
- [ ] 学生已脱敏:化名;可识别组合信息已模糊;文书引用≤2处且每处≤25字
- [ ] 文末有真实案例+隐私保护声明
- [ ] 项目事实(录取人数/课程设置/政策)均来自用户提供或已核实,无凭记忆编造

## 三、独创性清单

- [ ] 与参考文(竞品文、外部案例目录里的文章)跑过 12 字滑窗查重,命中只有校名、项目名、数字(结构、手法可用,句子必须重写)
- [ ] 学员原话、顾问寄语里的细节都来自本案真实素材,没有造出来的通用鸡汤
- [ ] 所有故事细节能在用户素材里找到出处;找不到出处的细节已删除或已向用户确认

## 四、案例文专项(交付前最后一遍)

- [ ] 反差在标题和前3段都出现了
- [ ] 主线一句话能复述("这个学生所有经历都在回答____")
- [ ] 服务动作≥3个,每个有数字/时间/场景之一
- [ ] 关系细节≥1个(编不出来的那种)
- [ ] 专业度冷知识≥1处
- [ ] **选校段没有三层名单**(D体2026-08-21硬规则):只挖最好那枚offer的课程与课号;最好的不是最终去向时写成录取后两个项目的权衡;禁止按录取结果倒推冲刺/匹配/保底
- [ ] **课号、课名、课程内容全部有据可查**(学生文书/官网/用户提供),没有一个是凭记忆写的
- [ ] **结尾没有金句、没有回收标题命题、没有首尾呼应**(D体2026-08-21硬规则):面试→放榜与去向→看见这个人→学员原话收住(2026-11-03;原话照录、标明是谁说的,没有合适原话才用一句祝愿)
- [ ] 选校段收句是本案自己的一句,没有沿用「列一份学校名单并不难……」这类固定句
- [ ] 建议功能按体例落实(D体小贴士1~2处 / B体第7问+小贴士 / 长页小贴士+结尾说明),条条可操作,不放在结尾四步之后
- [ ] 配图位已标注,caption承担服务证据
- [ ] CTA带钩子词
- [ ] 自夸形容词(专业/用心/负责/高效/贴心)计数=0
- [ ] 人称:叙事段没有「你」;「你」只出现在导语末句、IvyPath小贴士、建议、CTA、B体问句小标题和顾问寄语里
- [ ] `zh_lint.py` 无超限项,或超限项已逐条说明理由
