# 质检 Rubric(不过不交)

优先读用户库的完整版:`Obsiden_市场/01_品牌中枢/去AI味写作规范.md` + `品牌禁用语.md`。
本文件是离线精简版 + 案例文专用追加项。

## 一、去AI味自评(满分10,≥8才交付)

| 项 | 满分 | 扣分点 |
|---|---|---|
| 无AI高频词(赋能/打造/全方位/深耕/助力/保驾护航/至关重要/淋漓尽致/颠覆/闭环) | 2 | 每个扣1 |
| 句式:"不是X而是Y"≤1次(**D体放宽到≤3次且只用于加粗理念句**,见house-style.md);破折号连接半句≤1处;对仗三连(高效、专业、贴心)≤1次 | 2 | 每超一处扣0.5 |
| 无空心词(真正/其实/值得一提的是/或许/某种程度上/不得不说) | 1 | 每个扣0.5 |
| 每个"好/优秀/值得"都换成了具体数字或原因 | 2 | 每处空泛点评扣1 |
| 开头无"在当今…时代";结尾无"未来可期/拭目以待/综上所述";事实清单后不挂总结尾巴 | 2 | 各扣1 |
| 读起来像真人机构在讲一个真学生,不像通稿 | 1 | 主观 |

案例文高危AI腔(竞品清柚体的教训,专项排查):
"浓墨重彩的一笔""大放异彩""脱颖而出"(≤1次)"抛出橄榄枝"(≤1次,标题正文合计)"圆梦名校""厚积薄发"式四字对仗小标题、每段结尾的升华句。

## 二、合规清单(一票否决)

- [ ] 无禁用语:保录 / 100%录取 / 包装背景 / 走捷径 / 内部资源保证 / 名校随便拿 / 低分也稳了
- [ ] 不暗示与学校有特殊录取关系;不暗示代写、造假
- [ ] 不承诺结果、签证、实习、工作("这个案例不代表每个学生都适用,但策略值得参考"是标准姿势)
- [ ] 学生已脱敏:化名;可识别组合信息已模糊;文书引用≤2处且每处≤25字
- [ ] 文末有真实案例+隐私保护声明
- [ ] 项目事实(录取人数/课程设置/政策)均来自用户提供或已核实,无凭记忆编造

## 三、独创性清单

- [ ] 与参考的12篇竞品文无任何成句重合(结构、手法可用,句子必须重写)
- [ ] 金句来自本案学生/顾问的真实素材,不是造出来的通用鸡汤
- [ ] 所有故事细节能在用户素材里找到出处;找不到出处的细节已删除或已向用户确认

## 四、案例文专项(交付前最后一遍)

- [ ] 反差在标题和前3段都出现了
- [ ] 主线一句话能复述("这个学生所有经历都在回答____")
- [ ] 服务动作≥3个,每个有数字/时间/场景之一
- [ ] 关系细节≥1个(编不出来的那种)
- [ ] 专业度冷知识≥1处
- [ ] **选校段没有三层名单**(D体2026-08-21硬规则):只挖最好那枚offer的课程与课号,禁止按录取结果倒推冲刺/匹配/保底
- [ ] **课号、课名、课程内容全部有据可查**(学生文书/官网/用户提供),没有一个是凭记忆写的
- [ ] **结尾没有金句、没有回收标题命题、没有首尾呼应**(D体2026-08-21硬规则):面试→放榜与去向→看见这个人→祝愿收住
- [ ] 建议板块3条,条条可操作
- [ ] 配图位已标注,caption承担服务证据
- [ ] CTA带钩子词
- [ ] 自夸形容词(专业/用心/负责/高效/贴心)计数=0

## 五、用词DNA(自学习区,越用越准)

> 用户每次改稿后,把改动规律写成一条规则追加在这里。格式:`- [日期] 规则(来自:哪篇/哪处修改)`。
> 同时把开头钩子、口语连接词、收尾方式的真人句式攒进下面三个清单,写稿时优先从清单里挑,别自己造。

**开头钩子(真人句式库)**
- [2026-07-11] "{学生}的学术路径,始于{具体地点/场景}。"(来自:大阪山寺篇,场景白描开场是我们的默认开头)
- [2026-07-11] "他第一次意识到:____"(场景收束进认知)

**口语连接(转折/举例怎么说)**
- [2026-07-11] "我们没有急着让他____,而是____"(来自:大阪山寺篇)
- [2026-07-11] "这段经历看似和申请不直接相关,但其实非常重要。"
- [2026-07-11] "但他的情况不一样,____"(一般权衡→个案判断)
- [2026-07-11] "很多{画像}的学生都会遇到类似问题。"

**收尾方式**
- [2026-07-11] "有些申请的意义,不只是抵达一所学校。而是让____。"(命题闭环句式,内容每篇重造)
- [2026-07-11] "我们看到的是一个{三个真实形容}的学生"(先给人,再给金句)

**修改规则**
- [2026-07-11] 公众号案例文默认口吻=D体(house-style.md),竞品体例只作备选(来自:用户提供自家发表稿《大阪山寺》并指定为主模式)
- [2026-07-11] 结果/放榜段小标题必须用具体词(offer/录取/学校名),抽象意象("答案"等)只许在开头场景出现;"规避母本成句"应换意象,不是把具体词换成抽象词(来自:K同学D体版,用户把"答案接连到来"改回"offer接连到来")
- [2026-08-21] **选校段禁写三层名单,改单校课号深挖**。公开的只有录取结果不是完整申请list,按offer倒推分层=="选了的都录了",逻辑倒推没有意义。改成挑最好的一枚offer分析课程,逐门列课号,再用"看完这些课程,他发现____"让学生自己得出结论(来自:Z同学·罗格斯EE篇,Shawn 直接给了定稿段落)
- [2026-08-21] **结尾不再回收标题命题、不写金句、不做首尾呼应**。四步收住:面试(具体次数+复盘做法)→放榜列offer+去向+一个朴素现实的理由→"整个申请过程中,我们看到的是一个{三个真实形容}的学生"→一句祝愿。呼应式收尾读起来像表演(来自:同上,Shawn 直接给了定稿段落)
- [2026-08-21] **用户给的定稿文字优先于去AI规范**。Shawn 定的选校段收句里"真正"出现两次(空心词),照用不改;规范是给我们自己写初稿用的,不用来改用户的定稿(来自:同上)

完整DNA清单见 `house-style.md`(D体专属)。
