# 官网稿：案例长页与四栏短页

同一张案例卡可以出三种稿：公众号长文、官网案例长页、官网四栏短页。三种稿事实完全一致，篇幅和分节不同。官网长页可以和公众号长文共用正文，标题、导语按渠道分别写。

## 一、官网案例长页（D体）

版式、配色、图位以设计稿 `/网站开发/6、网站项目库与案例库/案例库设计/README.md` 为准，本文件只管文案。README 写于 2026-08-01，早于 8/21 的选校与结尾规则和 11/03 的标题规则，有六处新写长页按本文件执行。已上线的 /cases/49–52 保持原样，不回改（Daniel 2026-11-03 定）：

- 「写作口吻：第二人称你」→ 正文第三人称讲学生，机构自称「我们」，直接对读者说话的地方（Hero 正文末句、IvyPath小贴士、结尾说明、CTA）才用「你」；
- 「05 三层选校」→ 05 改为「选校：先对课号」（/cases/52 的节名是「先对课号，再排名单」，可沿用，但正文不放名单），不做三张分层卡片；新稿课程卡不写课号，课号进出处表（Daniel 2026-11-03 定）；
- 「结尾引言」→ 引言位放学员原话，全页正文最后一句就是学员自己的话；没有合适原话才删掉引言位，不写编辑金句；
- 「H1 两行，从{起点意象}到{录取终点}」→ H1 按 titles-hooks.md 写成一句讲事实的话，可在逗号处断成两行，不再用从…到…命题式（Daniel 2026-11-03 定）；
- 「节名 + 冒号 + 小标题」→ 页面小标题只写节号 + 一句话（house-style.md「小标题」），起点、问题诊断这些中文节名不出现在页面上，版式需要标签时用英文小字（Daniel 2026-11-03 定）；
- 「03 两张卡 + 灰底事实条 + 这一步为什么重要 + 金色注释块『IvyPath 做了什么』」「06 两张『打磨实例』竖卡」→ 改成按时间顺着讲的段落（house-style.md「正文：按时间顺着讲」），03、06 都用左窄右宽叙事版，`showProcessNotes` 默认关（Daniel 2026-11-03 定）。

### Hero 三处怎么分工（Daniel 2026-11-03 定稿）

| 位置 | 放什么 | 耶鲁资管样稿 |
|---|---|---|
| H1 | 最抓人的反差：一个数字 + 名校项目，可以写成问句 | GPA 3.6，她如何拿下耶鲁资管？ |
| 副题 | 分量：身份 +「N申N中」或奖学金（数字属实才写） | 罗格斯学姐7申7中，狂揽3.5万美金奖学金。 |
| 描述 | 一句话：短板 + 靠什么打动招生官（主线），不展开过程 | 经济学专业，没有线性代数，如何用 ESG 投资主线打动招生官。 |

三处不重复同一个事实；过程留给正文。

### SEO

- `<title>`：`GPA{数字}{短板}录取{最好的学校}{项目简称}：{X}同学{N}校录取案例｜IvyPath Advisory`。例：`GPA3.4罗格斯ECE录取哥大EE：Z同学五校录取案例｜IvyPath Advisory`。
- meta description ≤80 字：背景 + 短板 + 结果 + 一句方法，不用翻案句。
- H1 全页唯一；校名首次出现中英并列，之后用中文简称。
- 正文提到的项目优先内链到官网项目库页；相似案例和院校专区由站点生成。

## 二、官网四栏短页

短页固定四栏：为什么选择我们 / 申请难点 / 服务过程 / 顾问点评。2026-11-03 抓取时，36 个短页的四栏都没有正文，其中 22 页显示「案例详情整理中」。

| 栏 | 写什么 | 素材来源 | 字数 |
|---|---|---|---|
| 为什么选择我们 | 转介绍链 / 比较过哪几家 / 签约前哪一次沟通让他决定；写事实，不写「专业」「用心」 | 访谈第 1 问 | 60–120 |
| 申请难点 | 1–2 个具体短板，带数字（GPA、时间、背景缺口），写到学生当时担心什么 | 访谈第 2 问、案例卡 | 60–120 |
| 服务过程 | 3 个动作，每个有数字 / 时间 / 场景之一（文书几稿、几次 mock、对过入读项目的哪几门课）；可以写成 3 行 | 后端记录、访谈第 3–7 问 | 120–200 |
| 顾问点评 | 经手顾问第一人称，至少一个只有经手人才知道的细节；最后引学员的一句原话收住（引号原文），没有就用一句对同类学生的具体判断，不写金句 | 经手顾问 | 80–150 |

- 前三栏第三人称；顾问点评用「我」。四栏之间不重复同一件事。
- 缺素材的栏写【待补：缺什么，找谁】，不编；整页跑 `zh_lint.py --genre short`。
- **批量做**：一次 5–10 页。先出素材缺口表（学员 | 缺哪栏 | 要什么 | 系统位置 | 找谁，位置见 intake-form 第九节），后端补齐再成稿。
