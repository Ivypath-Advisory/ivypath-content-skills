# D体 · IvyPath主笔叙事体(默认口吻)

蒸馏自 IvyPath 已发表案例《从大阪山寺到哥大东亚文化研究:一个学生的热爱,如何被真正看见》(2026-07-07,Caroline/Elaine)。
**这是我们的口吻,新写案例文默认用D体**;A/B/C(见 structures.md)仅在素材形态更适合时选用。

## 和竞品体的本质区别

竞品是"晒结果"(offer堆叠+服务罗列),D体是**"讲道理给你看"**:每个服务动作都附带决策逻辑的解释,读者读完不止羡慕结果,还看懂了申请这件事该怎么想。信任来自"这家机构讲得清楚为什么",不是"这家机构晒得多"。

## 口吻定位

- 文气、克制、知识分子腔,但每句都在解释而非炫技;情感只在结尾释放一次
- 学生是"被看见的人",不是战利品:写他的热情、他的追问,机构是解读者和搭桥人
- 加粗给**理念句**(认知升维的那一句),不给形容词
- 人称:正文第三人称讲学生(他/她/X同学),机构自称「我们」;直接对读者说话的地方(导语末句、IvyPath小贴士、给同类同学的建议、CTA)才用「你」(2026-11-03 定,取代长页设计稿 README 的「第二人称你」)
- 板块间用 `•` 分隔;网络配图标注 `*配图源自网络`,学生素材标注 `学员供图,禁止转载`

## 结构模板(七段式)

```
0. 档案卡(IvyPath学员:X同学/本科院校/专业/GPA/录取结果bullet)
1. 场景开场:学生故事里最有画面感的一幕,电影式白描(150~250字)
   → 收在一个认知句:"他第一次意识到:____"
2. 信任起点:怎么认识我们的+找来时的焦虑(学生和家长的原话式疑问,用问句排列)
   → 我们对问题的重新定义,用正面陈述:"他要解决的是:____"(2026-11-03 改:旧模板「并不只是…而是」会占掉全篇唯一一次翻案句额度)
3. 背景补强(1~2个动作,每个 = 动作 + 为什么这么做):
   "我们没有急着让他____,而是____"
   每个动作后必须有一段"这为什么重要"的解释(教学式服务呈现)
4. 关键抉择(可选):学生来问建议的一个岔路口(交换/换专业/要不要考GRE),
   写清一般情况的权衡 → "但他的情况不一样" → 我们的判断和理由
5. 选校逻辑(固定模块3的D体写法)——**单校课号深挖法,不写三层名单**(2026-08-21 定,见下方专章):
   "不同学校的项目即使都叫 X,研究重点、课程结构和录取偏好也可能相差很大"
   → 挑最好的那枚 offer,逐门列课号+课名+这门课具体涉及什么;最好的 offer 不是最终去向时,这一段改写成「录取后的项目权衡」(见下方专章)
   → "看完这些课程,他发现____"(用课程结构反推出学生自己的诉求)
   → 收在本案自己的一句判断上:这几门课对这个学生意味着什么,用本案的课名和方向写,每篇不同(2026-11-03 定,不再用固定收句)
6. 文书打磨:改了几稿、谁参与(导师身份亮牌)、具体校准了什么(专业表达/避免写成游记)
   → 收束句:文书最后落在一个什么问题上(一句话说清主线)
7. 结果与收束——**简洁收尾,不回收命题**(2026-08-21 定,见下方专章):
   面试辅导(具体次数+做法) → offer列表一句带过 + 最终去向与一个朴素现实的理由
   → "整个申请过程中,我们看到的是一个{三个真实形容}的学生"
   → 用学员自己的一句话收住(2026-11-03 定);没有原话时用一句具体的祝愿。**不写金句、不呼应标题命题、不做首尾闭环。**
8. 声明:"本文源自 IvyPath 学员真实申请案例。未经许可,请勿转载。" + 低调CTA(一句+尾图)
```

## 选校段:只挖一所,不排三层(2026-08-21 硬规则;2026-11-03 补充)

**禁止写三层选校名单。** 理由:公众号案例文公开的只有**录取结果**,不是完整申请 list。按 offer 反推"第一层冲刺/第二层匹配/第三层保底",等于说"我们选的都录了",读者一眼看穿是循环论证,专业度反而掉。

正确写法——**挑最好的那枚 offer,把它的课程挖到课号级**:

1. 开头一句立观点:项目名称相同不代表内容相同(研究重点/课程结构/录取偏好)。
2. **逐门列课**:课号 + 课名 + 这门课具体涉及什么。4~5 门为宜,要覆盖学生主线的不同侧面。
   > 例(Z同学·哥大EE):ELEN E6873 统计信号处理与学习,涉及假设检验、信号检测、参数估计和信号估计;ELEN E4720 将机器学习直接应用于信号、信息和数据;ELEN E6860 则可以继续深入高级数字信号处理。此外,还有 EEOR E4650 工程凸优化,以及 ELEN E4830 图像处理与计算机视觉。
3. **让学生自己得出结论**:"看完这些课程,他发现,____"——用课程结构反推出他没说清楚的那个诉求。这一步是专业度的真正来源:不是我们替他判断,是课程表让他自己看明白了。
4. 收在本案上,不收在名单上:一句话说清这几门课对这个学生意味着什么,用本案的课名、方向和学生自己的诉求写。每篇都要换,不用固定收句(2026-11-03 定;Shawn 的定稿句「列一份学校名单并不难……」已上线页面里只有 /cases/52 用过,新稿不再沿用,否则会变成新的模板句)。

**最好的 offer 不是最终去向时:写成「录取后的项目权衡」**(2026-11-03 定)。学生放弃了最好的那枚 offer,按最好的那所深挖课号就和结尾的去向对不上。这时选校段改写录取后的取舍,仍然不写三层名单:

1. 一句交代处境:手上同时有 A(最好的)和 B(最后去的),两个项目方向相近,内容差在哪。
2. 两边各列 2~3 门最能说明差别的课(课号 + 课名 + 涉及什么),再加一个就业或资源上的具体差别(就业报告口径、毕业去向、地理位置、产业资源),都要有出处。
3. 写学生自己怎么比、最后为什么选 B,用他的理由和原话;我们只交代一起做了哪些比较(比如查了几届校友去向、问了哪位在读学生)。
4. 结尾四步的第 2 步只用一句话带过去向,不把这段权衡再讲一遍。

> 例(写法示意):UCSD 生统 × DS 那位学姐手上有耶鲁生统,最后去了西北 MLDS。按这种写法,就把耶鲁和西北各 2~3 门能说明差别的课列出来,再对照两个项目最新就业报告里的去向,最后落在她自己的理由上(她要的是工程取向、留美就业)。课号和就业数字都按官网核对后再写。

课号必须来自学生文书/官网/用户提供的真实素材,**不确定就问,绝不凭记忆编课号**——编错课号是这类写法唯一的致命伤。

每个课号的出处(官网课程页 URL / 课程要求 PDF / 文书 / 用户提供)写进发布信息,不写进正文。官网每年改课,上线前按出处复核一次。课程描述用官网原意转述,不加官网没有的内容。

## 结尾:简洁收住,不回收命题(2026-08-21 硬规则)

D体早期版本要求"金句闭环、呼应标题命题"。**该要求已废除。** 呼应式收尾读起来像在表演讲述,机构口吻要的是把话说完就停。

结尾四步,每步一段,不加戏:

1. **面试**:整理了往年面试题和经验 + 一对一模拟 + 具体次数 + 模拟后怎么复盘。
2. **放榜**:"他先后收到了 N 份录取:……"一句列完;最终去向 + **一个朴素现实的理由**(产业资源、地理位置、课程),不要把选校段的论证再搬一遍。
3. **看见这个人**:"整个申请过程中,我们看到的是一个{三个真实形容}的学生"。形容要从本案素材长出来。
4. **用学员自己的话收住**(2026-11-03 定):挑一句学员的原话放在最后,来源是学员访谈第 8 问、文书素材问卷或聊天记录,原文照录,不改写、不拔高,40 字以内,标明是谁说的(「他后来在问卷里写:"……"」或另起一行署「X同学」)。原话要具体(他接下来想做的事、给后来者的一条提醒、当时的一句心情),空泛的感谢不用。没有合适的原话时,才用一句具体的祝愿收住:"我们也祝愿他在{学校}的学习一切顺利,继续自己的{方向}探索之路。"

标题按 titles-hooks.md 写成一句人话(2026-11-03 起不再用命题式),结尾本来就不回收标题。

## 小标题:写一句让人想读下去的话(2026-11-03 Daniel 定)

小标题是一句完整的人话:写这一节里最具体、最出人意料的那件事,或者学生当时心里的那个问题,让读者扫一眼就想往下读。尽量带数字、校名、课名或具体动作。
- 不写「起点:」「问题诊断:」「选校:」「文书:」「放榜:」这类栏目名加冒号(Daniel 指出这样非常 AI);节号 01–07 保留,后面直接接这句话。
- 不用比喻和意象;不写「先…再…」「从…到…,让…」;不写带「让 / 找到 / 落地 / 看见 / 生长」的功能句;不用四字对仗;不写翻案句。
- 可以用转折和问句(却、没想到、是不是),转折必须是素材里真实发生的事;问句用学生或家长当时的原话式疑问。
**结果/放榜段的小标题必须带具体词(offer/录取/学校名),不用"答案""惊喜"这类抽象词——读者在结果段扫的就是offer两个字**(2026-07-11 规则保留)。

范例(罗格斯经济 → 耶鲁资管样稿,Daniel 2026-11-03 审过):
- 场景段 → 01 选校名单上出现了耶鲁,她和家人都没想到
- 问题段 → 02 没修过线代,申耶鲁是不是想多了?
- 动作段 → 03 Python 是加分项,她把力气都放在了实习上
- 选校段 → 04 拼量化比不过数学系,她决定主打 ESG
- 文书段 → 05 她的文书,从一次野生动物保护活动写起
- 放榜段 → 06 耶鲁最后一个放榜,7 个项目全录了
- 卡片、注释块的小标题可以短,写事实短语即可:开头写哪一次环保活动 / 每段实习交代两件事。
- 官网长页设计稿里的节名(起点 / 问题诊断 / 从兴趣到证据 / 选校……)只是内部分节名,不写进页面小标题;版式需要标签时用设计稿的英文小字(Origin / Diagnosis / Evidence …)。

同日上午定的「节名标签 + 冒号 + 事实短语」(如「01 起点:和家人去纽约见顾问」)已废除。

原「意象,功能」两段式和「从{X}到{Y},{动作}」及其范例(山寺之间,学术热爱的起点 / 从兴趣到证据,让热情真正落地 / 好的选校,找到最适合的空间)已于 2026-11-03 废除,开头场景段也不再用意象;已发表的《大阪山寺》不回改。

## 标题与摘要

- 标题:按 titles-hooks.md 的六种写法,写成一句讲事实的人话,用「她 / 他」或「{本科}学姐 / 学长」(2026-11-03 Daniel 定)。原 D体主标题「从{起点意象}到{录取终点}:{一个抽象命题}」已废除,已发表的《大阪山寺》原题不回改。
- 摘要(公众号description):{短板组合},怎么拿下{学校群}?一篇真实案例,拆解{这个学生的主线}是怎么一步步搭起来的。
  (2026-11-03 改:旧公式「答案不在于…而在于…」本身就是翻案句,会占掉全篇唯一一次「不是…而是」额度)

## 用词DNA(写稿时优先套用真实句式)

**开头钩子**
- "{学生}的{学术路径/申请故事},始于{一个具体地点/场景}。"
- 场景白描用动词链:"他沿着…攀登,在…诵经"
- "他第一次意识到:____"

**解释与转折**
- "我们没有急着让他____,而是____"
- "这段经历看似和申请不直接相关,但其实非常重要。"
- "如果单纯从{X}角度来看,____并不总是最优选择。但他的情况不一样,____"
- "很多{画像}的学生都会遇到类似问题。"(典型化,代入感开关)
- "招生官不能只看'{兴趣/热情}'本身。申请需要证据,需要经历,需要____"

**选校**
- "不同学校的项目即使都叫 {EE/ECE},研究重点、课程结构和录取偏好也可能相差很大。"
- "以{学校}为例,我们和他一门一门对过课号:____"
- "看完这些课程,他发现,____"
- ~~"列一份学校名单并不难,难的是让学生真正明白每所学校为什么适合自己。"~~ **不再沿用**(2026-11-03):选校段每篇用本案自己的一句收住。

**收尾**
- "整个申请过程中,我们看到的是一个{三个真实形容}的学生"
- 学员原话收尾:「他后来在问卷里写:"____"」(2026-11-03 起的默认结尾)
- "我们也祝愿他在{学校}的学习一切顺利,继续自己的{方向}探索之路。"(没有合适原话时用)
- ~~"有些申请的意义,不只是抵达一所学校。而是让____。"~~ **已废除**(2026-08-21):金句闭环式收尾像表演,改简洁收住。

**高频真词**:主线 / 落地 / 承接 / 看见 / 追问 / 拆解 / 画像 / 证据

## D体的去AI味特例

- "不是X,而是Y"(含「不只是…而是」「不在于…而在于」「并非…而是」)**每篇 ≤1 次**(2026-11-03 定,原 D体放宽的 ≤3 次作废),只许用在加粗的理念句,不许用在过渡、小结、小标题和结尾
- 「真正」编辑文字里每篇 ≤1、破折号连接半句每篇 ≤1;学员原话(引号内)和 Daniel/Shawn 的定稿句不计数
- DNA 句式(「我们没有急着让他____,而是____」「但他的情况不一样」「他第一次意识到:」)不按翻案腔处理,但每种句式每篇只用一次,反复出现就成了新模板
- 其余规则照旧执行(quality-check.md):无Tier1词、无空心词、无对仗三连、结尾不喊口号
- D体特有风险自查:①理念句加粗是否超过每板块1句 ②解释段是否变成说教(每段解释≤3句) ③场景白描是否堆形容词(动词优先)

## 固定模块在D体中的映射

①为什么选我们=段2信任起点 ②背景短板=段2 ③选校逻辑=段5(**单校课号深挖,非三层名单**) ④背景提升=段3 ⑤文书=段6 ⑥结果与去向=段7(**简洁收尾,不回收命题**) ⑦建议+CTA=D体可用「IvyPath小贴士」插播承担建议功能(段3/段5后各一处为宜),CTA低调收尾。
