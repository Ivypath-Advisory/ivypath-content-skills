# 标题与导语

## 标题：写成一句人话（2026-11-03 Daniel 定）

标题讲一件真实的事：这是谁（本科、专业），拿到了什么，中间有什么不寻常。读者扫一眼就知道这篇讲谁、和自己像不像。原来的九个标题公式（含 D体主标题用的「从{起点意象}到{录取终点}：{一个抽象命题}」）已废除：按公式写出来的标题冒号前后对称、带比喻，读起来像 AI。

结构参考 PH 和清柚的标题（2026-11-03 统计，两家全部标题见《清柚与PH案例标题_20261103.xlsx》）：

| | PH（484 篇） | 清柚（327 篇） |
|---|---|---|
| 中位长度 | 25 字 | 33 字 |
| 第一人称「我」 | 45% | 0 |
| 转折词（却、竟、最后、结果、一度、原本、但） | 21% | 0 |
| 「学姐 / 学长」 | 1% | 47% |
| 「N申N中」「连录」「大满贯」 | 0 | 27% |
| 套话动词（斩获、狂揽、收割、圆梦、逆袭……） | 15% | 71% |
| 感叹号 | 50% | 99% |

写法以 PH 为准：一个标题只放一个钩子，名校放在句尾当结果。钩子落在人身上：她一度怎么想、原本打算做什么、靠了什么意想不到的东西、在两个 offer 之间怎么选。清柚只借「{本科}学姐 / 学长」这个身份词，方便同校读者认出自己；它把分数、学校、录取数全堆进一句的写法不学。竞品标题只学结构，成句不得复用（12 字查重同样适用于标题）。

### 六种写法

| # | 写法 | 结构 | 示例（罗格斯经济→耶鲁资管样稿） |
|---|---|---|---|
| 1 | 意外的武器 | 靠「{X}」，{身份}拿下了{学校项目} | 罗格斯经济学姐靠「环保」，拿下了耶鲁资管 |
| 2 | 心理落差 | 一开始{没想过 / 差点放弃}{X}，最后{结果} | 一开始都没想过申耶鲁，最后耶鲁资管录了她 |
| 3 | 短板 + 却 | {短板}，{学校项目}却录了{身份} | 没修过线代，耶鲁资管却录了这位经济系学姐 |
| 4 | 选择 | 拒了{X}，选了{Y}；手上有{X}，最后去了{Y} | 手上有哥大和芝大，她最后去了耶鲁（去向确认后才能用） |
| 5 | 悬念 | {别的都有了}，{学校项目}却{迟迟没消息} | 别的录取都到了，耶鲁资管却迟迟没消息…… |
| 6 | 学员原话 | 拿到{X}后，她说：「……」 | 素材里有原话才用 |

出 5 个备选时从不同写法里取。

### 硬规则

- 一个钩子：一个标题只讲一件事，15~25 字。GPA、录取数、奖学金金额放副题、导语和 SEO 标题，不往标题里堆（2026-11-03 Daniel 指出堆数字的标题「冗余和呆」）。学校 ≤2 个。
- 转折要真：却、竟、最后、结果、一度、原本可以用，但转折必须是素材里真实发生的事（她当时没信心、耶鲁迟迟没放榜）；不拿事实做文字游戏，不写抽象的反转。
- 人称：D体和官网用「她 / 他」或「{本科}学姐 / 学长」；第一人称「我」只用在 B体和写法 6，而且必须是学员说过或认可的话。
- 不写：冒号前后对称的命题句；比喻和抽象词（这一课、被看见、破局、之路、答案、密码）；翻案句；套话动词（斩获、收割、拿到手软、抛出橄榄枝、圆梦、怒下、喜提、狂揽、霸气）；「N申N中」「大满贯」（会公开申请总数，与铁律 0 冲突）；「也能」（读起来像在向读者承诺）。zh_lint 会查标题行。
- 感叹号：公众号最多一个；官网 H1 不用。不用「震惊 / 惊呆」式标题党；不承诺。
- 官网长页：H1 用上面的写法，可以在逗号处断成两行；副题只补一个 H1 没说的钩子（短板、当时的心理、奖学金），一句话，不解释方法。SEO 标题格式见 web-page.md，数字放在那里。

## 四个导语公式

**1. 典型化画像式(B体默认)**

> 今天分享的J同学,是我们从大二就开始规划的学员。她的情况其实很典型:本科背景不错,自我驱动力强,但面临两个核心问题:一是____,二是____。最终她拿到____。以下是她的申请经验,希望对同样在准备的你有参考。

要点:第一段就让目标读者认出自己。"很典型"三个字是代入感开关。

**2. 冷开场信任反转式**

> 第一次接触O同学时,他的家人明确表达了对留学机构的不信任——本科申请踩过雷,老师敷衍,结果和DIY没区别。

要点:用"不信任中介"开场。敢写这个的机构,读者反而信。适合有"前一家中介踩坑"素材的案例。

**3. 短句排比预告式(小红书基因)**

> GPA没掉过链子/科研实习也扎实/可一到写文书就懵了/经历一堆,主线呢?

要点:一行一句,四句内完成"强项-强项-短板-悬念"。适合导语后直接进档案卡的快节奏开篇。

**4. 战绩背书式(C体默认)**

> 近两年,我们拿下N枚{项目}录取。今年这枚,是难度最高的一枚:学生的实习横跨四个不相关的行业。

要点:先亮账面,再抛本案反差。数字必须真实。

## 结果呈现的写法(放榜段)

- **D体与官网长页**:按 house-style.md「结尾」四步,offer 一句列完,不详写收到时刻、不做时间差对比
- **B体**:学员自己讲收到第一封 offer 的场景,原话照留;编辑不另加渲染
- **带奖必写金额**:$60,000比"高额奖学金"有力十倍
- **克制收尾**:结果后不加"这证明了我们的实力"式自夸,让数字自己说话;最后用学员原话收住(house-style.md 结尾第 4 步)
