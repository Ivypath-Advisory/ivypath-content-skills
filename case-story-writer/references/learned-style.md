# 改稿学习记录（用词 DNA 自学习区）

Daniel 或 Shawn 改过案例成稿后，把改动规律记在这里。规则改动一律先提交到 GitHub 仓库 `Ivypath-Advisory/ivypath-content-skills`，再重新生成 Claude 账号加载器（见仓库 AGENTS.md）。

## 怎么记

1. **只从 Daniel、Shawn 的改稿里学。** 实习生的回稿、批改记录、顾问随手改的错字不进规则。
2. **先分流，再记：**
   - 写法规则（结构、句式、小标题、口吻）→ 记为候选，转正后写进 house-style.md 或 structures.md
   - 检查规则（禁用词、限额、必查项）→ 记为候选，转正后写进 quality-check.md，能自动查的同时加进 `scripts/zh_lint.py`
   - 本篇事实修正（数字、校名、课号）→ 不进规则，只改稿
   - 只针对这一篇的取舍 → 不进规则
3. **格式：** `- [日期][状态] 规则（来自：哪篇 / 哪处修改；谁改的）`。状态：候选 → 转正 → 已废除。
4. **转正：** 同一条候选在之后连续 3 篇里没被推翻，交用户确认后转正。用户直接说「以后都这样」的，当场转正。
5. **废除：** 新规则推翻旧规则时，旧条目标「已废除」并写明被哪条取代，不删除。
6. **定稿文字优先：** Daniel / Shawn 给的定稿句照用，不按去 AI 规范改；需要 lint 跳过的定稿句收进下方「定稿保护句」。
