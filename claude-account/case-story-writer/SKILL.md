# 案例文生产线

把一个真实学生的申请故事，加工成一篇能带来咨询的案例文。

**核心公式：**

> 一个「按理说不该录」的反差 + 一条把所有经历串起来的主线 + 3~5 个具体到可验证的服务动作 + 1~2 个编不出来的关系细节 + 一枚 offer 的课号级深挖 + 结果 + 让读者对号入座的出口（建议 / IvyPath小贴士 / CTA）

标题负责打开率，档案卡负责搜索与信任，反差负责读完，服务细节负责「这机构靠谱」，课号深挖负责专业度，代入感负责收藏和私信。

## 规则来源与优先级（冲突时按这个顺序）

1. **Daniel / Shawn 给的定稿文字**：照用，不按去 AI 规范改（规范是给我们写初稿用的）。
2. **本 skill 与 ivypath-humanize-zh**（GitHub 私有仓库 `Ivypath-Advisory/ivypath-content-skills` 维护，最新）。
3. **市场库 `01_品牌中枢/去AI味写作规范.md`、`品牌禁用语.md`**：只补本 skill 没写到的条目（如新增禁用语）；与本 skill 冲突时按本 skill。品牌中枢的规范最后改于 2026-07-14，早于本 skill 的 2026-08-21 规则。

## 铁律（先读，贯穿全程）

0. **不做逻辑倒推**（2026-08-21）：案例文只公开录取结果，不公开完整申请名单。任何「从结果反推我们当初判断多准」的写法（三层选校名单、「果然如我们所料」、按 offer 排冲刺 / 匹配 / 保底）读者一眼看穿是自证，专业度不升反降。专业度只能来自**别处看不到的具体信息**（课号、课程内容、项目机制），不能来自结果本身。
1. **真实至上**：所有事实（背景、动作、结果、细节）只能来自用户提供的素材或后端记录。缺了就问，绝不编造。宁可少一个细节，不造一个细节。**课号、课名、项目政策尤其不许凭记忆写**，只能来自官网、学生文书或用户提供的材料；写错一个课号，整段专业度归零。
2. **独创性**：参考文（竞品文、外部案例目录里的文章）的结构、手法可以用，**成句、比喻、金句一律不得搬运**。成稿与参考文跑 12 字滑窗查重（`scripts/zh_lint.py --src`），命中只能是校名、项目名、数字。
3. **隐私脱敏**：学生用化名 / 首字母；可识别信息（小众社团职位、独家经历组合）做模糊处理；录取列表保留（这是卖点），敏感时征询用户。
4. **合规红线**：禁用语按 `references/quality-check.md` 第二节（保录 / 包过 / 保证 / 100%录取 / 包装背景 / 走捷径 / 内部资源 / 最强 / 全美第一等）；不暗示与校方特殊关系；不承诺结果；文末带真实案例声明。
5. **口吻**：正文第三人称讲学生（他 / 她 / X同学），机构自称「我们」；直接对读者说话的地方（导语末句、IvyPath小贴士、给同类同学的建议、CTA）才用「你」。B体的学员答问用学员第一人称，顾问寄语可以用「你」对学生说话。优势全部用具体动作和事实说话。
6. **前东家物料一张不用**；offer 原件找学生要（见 `references/images.md`）。

## 两个入口

- **入口1 · 从素材生成**（默认）：用户给学生案例卡 / 访谈问卷 / 文书 / 后端记录 → 走下方 Step 0~7。
- **入口2 · 改稿模式**：用户给一篇完整的已有稿子（旧稿、学生自述、前东家时期经手的自家学生稿）要求改成我们的形式 → 先读 `references/rewrite-mode.md` 走事实提取与权属确认，再并入 Step 2 之后的流程。改稿铁律：**只继承事实，不继承表达**；原稿的句子、比喻、小标题一律重写，且必须补入 ≥2 个原稿没有的一手细节。

## 固定模块清单（每篇必含）

无论哪个入口、哪种体例，成稿必须覆盖以下模块（素材实在没有的，问过用户后可省②④，其余不可省；四栏短页的精简对应见 `references/web-page.md`）：

| # | 模块 | 承载的功能 |
|---|---|---|
| 1 | 为什么选择我们（转介绍链 / 与其他机构的对比 / 签约前的一次专业展示） | 转化 |
| 2 | 背景与短板（档案卡 + 反差，学生找来时的状态） | 代入 |
| 3 | 选校逻辑：**挑最好的一枚 offer 深挖课程与课号**；最好的不是最终去向时，写成录取后两个项目的权衡（各列几门课 + 学生的取舍理由）；含 ≥1 处项目冷知识。**禁写冲刺 / 匹配 / 保底三层名单** | 专业度 |
| 4 | 背景提升动作（实习 / 科研 / 标化策略，具体到数字） | 服务证据 |
| 5 | 文书提升过程（主线怎么找到的、具体某一篇怎么改、学生思维被扭转的瞬间） | 服务证据 + 专业度 |
| 6 | 结果与去向：面试动作 + offer 列表 + 最终去哪及一个朴素理由，**最后用学员自己的一句话收住**；不回收标题命题，不写金句 | 结果 + 专业度 |
| 7 | 给同类读者的建议 + CTA：D体由 1~2 处「IvyPath小贴士」承担，不另设建议板块；B体是学员第 7 问的建议 + 小贴士；官网长页是小贴士 / 注释块 + 结尾说明与按钮 | 收藏 + 转化 |

写完后逐项打勾；缺哪个模块，回素材里找或问用户。

## 工作流

### Step 0 · 读品牌上下文

挂载了 `Obsiden_市场`（Shawn 的市场库）时，读 `01_品牌中枢/品牌禁用语.md`、`01_品牌中枢/用户画像.md`（决定反差怎么选、建议写给谁）；`去AI味写作规范.md` 只补本 skill 没写到的条目（见「规则来源与优先级」）。读不到市场库时，按本 skill 的 `references/quality-check.md` 与 ivypath-humanize-zh 执行。

### Step 1 · 收集素材

按 `references/intake-form.md` 核对素材完整度。素材来源（可叠加）：

- 学生案例卡（市场库模板：`04_案例素材库/_模板_学生案例卡.md`）
- **学员访谈问卷**（`references/intake-form.md` 第八节的 8 问提纲，由班主任或后端顾问发给学生书面回答）：B体和四栏短页的主要素材
- 后端服务记录：定校书、文书分配表、推荐人库、申请管理（面试 / Offer 材料）、学业规划、学生服务群（位置与找谁见 intake-form 第九节）
- 学生文书（PDF / docx / 文本）：按 intake-form 的「文书使用规则」提炼，不直接大段引用

**必需项缺失时，用 AskUserQuestion 一次性问全**（背景数字、最大短板、我们做的具体动作、结果列表、最终去向、能否出镜访谈）。不挤牙膏式追问。

### Step 1.5 · 找参考案例（可选）

要找「同本科 / 同方向写得好的文章」学结构时，按 `references/reference-cases.md` 查外部案例目录。参考文只学结构和信息槽，句子一律不用；C 级文章永不发布。

### Step 2 · 选体例与输出形态

**体例**（默认 D体，读 `references/house-style.md`；A/B/C 见 `references/structures.md`）：

| 手头素材 | 体例 |
|---|---|
| 默认：顾问视角素材足、有场景感细节，旗舰篇 | **D 主笔叙事体** |
| 有学员访谈问卷 / 学员愿意出镜答问，批量篇 | **B 学员访谈体** |
| 故事平但方法论强 / 想立导师专业人设 | **C 导师专访复盘体** |
| A 第三人称成长叙事体 | 已被 D体取代，仅作竞品结构参考 |

**输出形态**（同一张案例卡，按用户要求出一种或几种；读 `references/web-page.md`）：

| 形态 | 用途 | 体例 |
|---|---|---|
| 公众号长文 | 公众号推文 | D / B / C |
| 官网案例长页 | 官网 /cases/ 长页，按长页设计稿分节 | D |
| 官网四栏短页 | 官网 /cases/ 短页的「为什么选择我们 / 申请难点 / 服务过程 / 顾问点评」 | 素材同 B体 |

### Step 3 · 定反差与主线

- **反差**：从素材里找那个「按理说不该录」的点（低 GPA / 标化弱 / 转专业 / 实习散 / 起步晚 / 背景普通）。没有明显短板时，用「选择反差」（放弃 X 选 Y / 不卷保研 / 意外底牌）。
- **主线**：一句话说清「这个学生所有经历都在回答同一个问题」。文书里通常藏着现成主线，优先从文书提炼。
- 反差要和目标读者画像匹配：写给谁看，就选谁的痛点当反差。

### Step 4 · 写作

1. **标题**：按 `references/titles-hooks.md` 出 5 个备选（不同写法各一，写成一句人话）；官网长页另出 SEO 标题（格式见 web-page.md）。
2. **导语**：同文件的导语公式，首段完成「典型化画像 + 难点预告 + 结果预告」。
3. **正文**：按选定体例的模板写。每写一处「我们做了什么」，对照 `references/service-trust.md`：有数字、有时间、有场景三者之一，否则删掉重写。
4. **选校段**：按 house-style.md「选校段」专章，单校课号深挖（最好的 offer 不是最终去向时写录取后的项目权衡）；收句每篇用本案自己的一句，不用固定句；课号逐个标出处（官网 URL / 文书 / 用户提供），出处写进发布信息，不写进正文。
5. **结尾**：按 house-style.md「结尾」专章四步收住，最后一句是学员原话；素材里没有合适原话时，Step 1 就向后端要学员访谈第 8 问的回答。
6. **代入感出口**：按固定模块 7 的体例分工写建议（小贴士里的建议要可操作）+ 结尾 CTA（带具体钩子词）。建议不放在结尾四步之后，正文收在学员原话上，后面只接 CTA 和声明。
7. **配图位**：正文中用 `[配图:____]` 标注建议插图位置，caption 承担「服务证据」功能；按 `references/images.md` 附**配图生产单**。

### Step 5 · 质检（不过不交）

1. 跑检查脚本：`python3 scripts/zh_lint.py 成稿.md --genre case [--src 参考文.txt --allow 校名项目名.txt] [--protect 定稿句.txt]`，超限项必须改到限额内或说明理由。B体的学员答问段用 `::: 原话` 与 `:::` 两行包起来（发布前删掉这两行），lint 不把它计入限额。
2. 按 `references/quality-check.md` 过合规、独创性、案例文专项清单。
3. 调用 ivypath-humanize-zh（案例文档）做语言终审。
4. 每个服务呈现点都有「数字 / 时间 / 场景」三者之一。

### Step 6 · 交付与归档

- 输出：成稿（含 5 个标题备选、配图位、文末声明与 CTA）+ 一段「发布信息」（体例、输出形态、反差、主线、课号出处、lint 结果、建议钩子词、【需顾问确认】项）。
- 挂载了市场库时存到 `Obsiden_市场/07_生产发布库/`（文件名 `YYYYMMDD_案例文_{学生代号}.md`），否则交付文件并提示用户保存。

### Step 7 · 越用越准（学习闭环）

Daniel 或 Shawn 改过成稿后：对比改动，按 `references/learned-style.md` 的分流规则提炼 1~3 条，记入该文件的「候选」区，交给用户确认后提交 GitHub。实习生的改动、批改记录不进规则。同一条候选连续 3 篇没被推翻，才转正写进 house-style.md 或 quality-check.md。

## 离线核心规则（读不到仓库时按此执行）

### D体七段式（默认体例，旗舰篇）

```
0. 档案卡：IvyPath学员 X同学 / 本科院校 / 专业 / GPA / 标化 / 录取结果 bullet / 最终去向
1. 场景开场：学生故事里最有画面感的一幕，白描，动词优先（150~250字），收在「他第一次意识到：____」
2. 信任起点：怎么认识我们的 + 找来时的焦虑（学生和家长原话式问句排列）→ 用正面陈述重新定义他要解决的问题
3. 背景补强：1~2 个动作，每个 = 动作 + 一段「这为什么重要」（「我们没有急着让他____，而是____」全篇一次）
4. 关键抉择（可选）：一般情况的权衡 →「但他的情况不一样」→ 我们的判断和理由
5. 选校：单校课号深挖（见下）
6. 文书打磨：改了几稿、谁参与（导师身份）、具体校准了什么 → 一句话说清文书最后落在什么问题上
7. 结尾四步（见下）
8. 声明「本文源自 IvyPath 学员真实申请案例。未经许可，请勿转载。」+ 低调 CTA
```

**选校：只挖一所，不排三层。** 公开的只有录取结果，按 offer 倒推冲刺 / 匹配 / 保底等于说「选了的都录了」。写法：一句立观点（同名项目的研究重点、课程结构、录取偏好可能差很大）→ 挑最好的那枚 offer，逐门列 4~5 门课的课号 + 课名 + 涉及什么 →「看完这些课程，他发现，____」（用课程结构反推出他自己的诉求）→ 收在本案自己的一句判断上，每篇不同，不用固定句。最好的 offer 不是最终去向时，写成录取后的项目权衡：两边各 2~3 门能说明差别的课 + 一项就业或资源差别 + 学生自己的取舍理由。课号只能来自官网课程页、学生文书或用户提供的材料，出处写进发布信息；查不到就问，绝不凭记忆写。

**结尾四步，每步一段，不加戏：** ① 面试：整理往年面试题 + 一对一模拟 + 具体次数 + 模拟后怎么复盘；②「他先后收到了 N 份录取：……」一句列完，最终去向 + 一个朴素现实的理由；③「整个申请过程中，我们看到的是一个{三个真实形容}的学生」；④ 用学员自己的一句话收住（访谈第 8 问、文书素材问卷或聊天记录里的原话，照录不改，≤40 字，标明是谁说的）；没有合适原话时，才用「我们也祝愿他在{学校}的学习一切顺利，继续自己的{方向}探索之路。」不写金句，不回收标题命题，不做首尾呼应。

### B体（学员访谈体，批量篇）

编辑导语（150~300字）→ 学员档案卡 → 顾问寄语（经手顾问第一人称，对学生用「你」，至少一个只有经手人知道的细节，一句祝愿收住）→ 学员第一人称正文（按访谈问题分节，小标题用问句或两行式，第二行不写翻案句；最后一节是学员给后来者的建议，全文收在学员的话上）→ 中间每 2~3 节一个「IvyPath小贴士」→ CTA + 声明。整理学员回答只做删减、排序、衔接，不替学员加判断句和升华句；口语、自嘲、英文夹杂照留。

学员访谈 8 问：① 怎么找到我们、比过谁、为什么定下来 ② 刚开始最担心什么 ③ 最后去的项目看了哪几门课、为什么是它 ④ 文书改了几稿、改动最大的一次改了什么 ⑤ 推荐信找了谁、怎么开口 ⑥ 面试准备了几次、印象最深的问题 ⑦ 有没有没录上或主动放弃的项目、拿到 offer 后犹豫过什么 ⑧ 给背景相似的同学一条建议。

每篇硬性下限：一个没录上或主动放弃的项目和原因；一个犹豫过的决定；具名角色加上具体动作；至少一个数字。

### 官网稿

- **长页**：Hero（H1 是一句讲事实的话，可在逗号处断成两行，写法同下方「标题」；副题写一句事实，不写命题；数据条）→ 录取结果海报 → 01 起点 → 02 问题诊断 → 03 从兴趣到证据 → 04 关键经历 → 05 选校：先对课号（最好那枚 offer 的课程卡片；没去最好那所时改成两个项目的对比；不做三层卡片，不补名单）→ 06 文书打磨 → 07 放榜（结尾四步的前三步）→ 4 个可核实数字 → 结尾引言位放学员原话，没有合适原话才删 → 页脚声明。已上线的 /cases/49–52 不回改。SEO 标题：`GPA{数字}{短板}录取{学校}{项目}：{X}同学{N}校录取案例｜IvyPath Advisory`。
- **四栏短页**：为什么选择我们（60~120字，事实）/ 申请难点（60~120字，带数字）/ 服务过程（120~200字，3 个动作各带数字 / 时间 / 场景）/ 顾问点评（80~150字，经手顾问第一人称，一个只有经手人知道的细节，最后引学员一句原话收住）。缺素材写【待补：缺什么，找谁】。

### 小标题

写事实短语，尽量带数字、校名、课名或具体动作（和家人去纽约见顾问 / 三段金融实习，第一段在投行 / 耶鲁资管的 5 门课 / 7 份录取，耶鲁最后一个出结果）。不用比喻、意象、四字对仗，不写「先…再…」「从…到…，让…」和带「让 / 找到 / 落地」的功能句；放榜段必须带 offer / 录取 / 校名；长页节名标签保留，冒号后半句按此写。卡片和注释块标题同样写法。

### 句式限额与必查项

- 每篇：「不是…而是」（含不只是 / 不在于 / 并非…而是）≤1，只用在加粗理念句；「真正」≤1；破折号连接半句 ≤1；四栏短页三项都是 0。学员原话（引号内、B体 `::: 原话` 区）、定稿保护句和 DNA 句式不计。
- 选校段不再用「列一份学校名单并不难……」这句固定收句，每篇写本案自己的一句。
- 人称：正文第三人称讲学生，机构自称「我们」；导语末句、IvyPath小贴士、建议板块、CTA 才用「你」。
- 每个「我们做了什么」有数字 / 时间 / 场景之一；自夸形容词（专业 / 用心 / 负责 / 高效 / 贴心）= 0；服务动作 ≥3、关系细节 ≥1、项目冷知识 ≥1。
- 合规：不出现保录 / 包过 / 保证 / 100%录取 / 包装背景 / 走捷径 / 内部资源 / 名校随便拿 / 低分也稳了 / 最强 / 全美第一、行业第一这类「第一」；不承诺结果；学生化名，可识别组合信息模糊化，文书引用 ≤2 处且每处 ≤25 字。
- 独创性：参考文只学结构，与参考文 12 字以上连续相同的句子必须改（校名、项目名、数字除外）。
- offer 图：找学生要原件，不用前东家物料；打码姓名、称呼行、地址、学号 / 申请号、邮箱、电话、签名、二维码、照片，保留信头、校名、项目名、祝贺段、奖学金金额；排名写 USNWR 全美综排及年份，上线前市场确认。

### 标题（出 5 个备选，不同写法各一，写成一句人话）

一个标题只放一个钩子，名校放句尾当结果。写法以 PH 为准（PH 45% 用第一人称、21% 带转折）；清柚的「{本科}学姐 / 学长」、「N申N中」和狂揽、斩获这类动词可以借，堆数字和连用感叹号不学。成句不搬。

| 写法 | 结构 | 示例 |
|---|---|---|
| 1 意外的武器 | 靠「{X}」，{身份}拿下了{学校项目} | 罗格斯经济学姐靠「环保」，拿下了耶鲁资管 |
| 2 心理落差 | 一开始{没想过 / 差点放弃}{X}，最后{结果} | 一开始都没想过申耶鲁，最后耶鲁资管录了她 |
| 3 短板 + 却 | {短板}，{学校项目}却录了{身份} | 没修过线代，耶鲁资管却录了这位经济系学姐 |
| 4 选择 | 拒了{X}，选了{Y}；手上有{X}，最后去了{Y} | 手上有哥大和芝大，她最后去了耶鲁（去向确认后才能用） |
| 5 悬念 | {别的都有了}，{学校项目}却{迟迟没消息} | 别的录取都到了，耶鲁资管却迟迟没消息…… |
| 6 学员原话 | 拿到{X}后，她说：「……」 | 素材里有原话才用 |

15~25 字，学校 ≤2 个；GPA、录取数、奖学金放副题、导语和 SEO 标题，不往标题里堆。转折词（却、竟、最后、结果、一度、原本）可以用，转折必须是真实发生的事。D体和官网用「她 / 他」或「{本科}学姐 / 学长」，「我」只用在 B体和学员原话。不写冒号命题句、比喻和抽象词（这一课、被看见、破局、之路、答案、密码）、翻案句、「也能」。「N申N中」可以用，前提是申请数和录取数都属实，正文仍不列完整申请名单；狂揽、斩获、拿下这类动词一个标题用一个就够。公众号感叹号最多一个，官网 H1 不用；官网副题只补一个 H1 没说的钩子。不用「震惊」式标题党，不承诺。
