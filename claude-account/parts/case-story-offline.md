## 离线核心规则（读不到仓库时按此执行）

### D体七段式（默认体例，旗舰篇）

```
0. 档案卡：IvyPath学员 X同学 / 本科院校 / 专业 / GPA / 标化 / 录取结果 bullet / 最终去向
1. 场景开场：学生故事里最有画面感的一幕，白描，动词优先（150~250字），收在「他第一次意识到：____」
2. 信任起点：怎么认识我们的 + 找来时的焦虑（学生和家长原话式问句排列）→ 用正面陈述重新定义他要解决的问题
3. 背景补强：1~2 个动作，每个 = 动作 + 一段「这为什么重要」（「我们没有急着让他____，而是____」全篇一次）
4. 关键抉择（可选）：一般情况的权衡 →「但他的情况不一样」→ 我们的判断和理由
5. 选校：单校课号深挖（见下）
6. 文书打磨：改了几稿、谁参与（导师身份）、具体校准了什么 → 一句话说清文书最后落在什么问题上
7. 结尾四步（见下）
8. 声明「本文源自 IvyPath 学员真实申请案例。未经许可，请勿转载。」+ 低调 CTA
```

**选校：只挖一所，不排三层。** 公开的只有录取结果，按 offer 倒推冲刺 / 匹配 / 保底等于说「选了的都录了」。写法：一句立观点（同名项目的研究重点、课程结构、录取偏好可能差很大）→ 挑最终去向那枚 offer，逐门列 4~5 门课的课号 + 课名 + 涉及什么 →「看完这些课程，他发现，____」（用课程结构反推出他自己的诉求）→ 收在方法上。课号只能来自官网课程页、学生文书或用户提供的材料，出处写进发布信息；查不到就问，绝不凭记忆写。

**结尾四步，每步一段，不加戏：** ① 面试：整理往年面试题 + 一对一模拟 + 具体次数 + 模拟后怎么复盘；②「他先后收到了 N 份录取：……」一句列完，最终去向 + 一个朴素现实的理由；③「整个申请过程中，我们看到的是一个{三个真实形容}的学生」；④「我们也祝愿他在{学校}的学习一切顺利，继续自己的{方向}探索之路。」不写金句，不回收标题命题，不做首尾呼应。

### B体（学员访谈体，批量篇）

编辑导语（150~300字）→ 学员档案卡 → 学员第一人称正文（按访谈问题分节，小标题用问句或两行式，第二行不写翻案句）→ 每 2~3 节一个「IvyPath小贴士」→ 文末顾问寄语（经手顾问第一人称，对学生用「你」，至少一个只有经手人知道的细节，一句祝愿收住）→ CTA + 声明。整理学员回答只做删减、排序、衔接，不替学员加判断句和升华句；口语、自嘲、英文夹杂照留。

学员访谈 8 问：① 怎么找到我们、比过谁、为什么定下来 ② 刚开始最担心什么 ③ 最后去的项目看了哪几门课、为什么是它 ④ 文书改了几稿、改动最大的一次改了什么 ⑤ 推荐信找了谁、怎么开口 ⑥ 面试准备了几次、印象最深的问题 ⑦ 有没有没录上或主动放弃的项目、拿到 offer 后犹豫过什么 ⑧ 给背景相似的同学一条建议。

每篇硬性下限：一个没录上或主动放弃的项目和原因；一个犹豫过的决定；具名角色加上具体动作；至少一个数字。

### 官网稿

- **长页**：Hero（H1 两行「从{起点意象}，/ 到{录取终点}」+ 副题 + 数据条）→ 录取结果海报 → 01 起点 → 02 问题诊断 → 03 从兴趣到证据 → 04 关键经历 → 05 选校：先对课号，再排名单（课程卡片，不做三层卡片）→ 06 文书打磨 → 07 放榜（结尾四步）→ 4 个可核实数字 → 结尾引言位只放学员原话，没有就删 → 页脚声明。SEO 标题：`GPA{数字}{短板}录取{学校}{项目}：{X}同学{N}校录取案例｜IvyPath Advisory`。
- **四栏短页**：为什么选择我们（60~120字，事实）/ 申请难点（60~120字，带数字）/ 服务过程（120~200字，3 个动作各带数字 / 时间 / 场景）/ 顾问点评（80~150字，经手顾问第一人称，一个只有经手人知道的细节）。缺素材写【待补：缺什么，找谁】。

### 句式限额与必查项

- 每篇：「不是…而是」（含不只是 / 不在于 / 并非…而是）≤1，只用在加粗理念句；「真正」≤1；破折号连接半句 ≤1；四栏短页三项都是 0。学员原话（引号内）和定稿保护句不计。
- 定稿保护句（Shawn 定稿，照用）：「列一份学校名单并不难，难的是让学生真正明白每所学校为什么适合自己。这样筛出来的，才是他拿到录取后真正愿意去的项目。」
- 人称：正文第三人称讲学生，机构自称「我们」；导语末句、IvyPath小贴士、建议板块、CTA 才用「你」。
- 每个「我们做了什么」有数字 / 时间 / 场景之一；自夸形容词（专业 / 用心 / 负责 / 高效 / 贴心）= 0；服务动作 ≥3、关系细节 ≥1、项目冷知识 ≥1。
- 合规：不出现保录 / 100%录取 / 包装背景 / 走捷径 / 内部资源保证；不承诺结果；学生化名，可识别组合信息模糊化，文书引用 ≤2 处且每处 ≤25 字。
- 独创性：参考文只学结构，与参考文 12 字以上连续相同的句子必须改（校名、项目名、数字除外）。
- offer 图：找学生要原件，不用前东家物料；打码姓名、称呼行、地址、学号 / 申请号、邮箱、电话、签名、二维码、照片，保留信头、校名、项目名、祝贺段、奖学金金额；排名写 USNWR 全美综排及年份，上线前市场确认。
